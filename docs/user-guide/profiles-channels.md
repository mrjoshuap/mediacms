# Profiles & Channels

Customize your profile and create channels to organize and showcase your content.

## User Profiles

### Viewing Your Profile

1. Click on your username in the top-right
2. Select **Profile** or **My Profile**
3. View your profile page

### Editing Your Profile

1. Navigate to your profile
2. Click **Edit Profile**
3. Update information:
   - **Name**: Your display name
   - **Username**: Your unique identifier
   - **Bio/Description**: About you
   - **Location**: Your location
   - **Profile Picture**: Upload an avatar
   - **Contact**: Enable/disable contact options

4. Click **Save**

### Profile Features

Your profile displays:
- **Media Count**: Number of media items you've uploaded
- **Media Gallery**: Your uploaded content
- **Playlists**: Your created playlists
- **About**: Your bio and information
- **Contact**: Contact options (if enabled)

## Channels

Channels allow you to organize your content into themed collections.

### Creating a Channel

1. Navigate to **Channels** (if available)
2. Click **Create Channel**
3. Enter:
   - **Title**: Channel name
   - **Description**: What the channel is about
4. Click **Create**

### Adding Media to Channels

1. Edit your media
2. Select a channel from the dropdown
3. Save changes

Or:

1. Open your channel
2. Click **Add Media**
3. Select media to add

### Managing Channels

- **Edit**: Change name and description
- **Delete**: Remove channel (media remains)
- **Reorder**: Organize channel order
- **Privacy**: Set channel visibility

## Profile Customization

### Profile Picture

1. Edit your profile
2. Click **Upload Picture**
3. Select an image
4. Crop if needed
5. Save

**Recommended**: Square images, at least 200x200 pixels

### Cover Image

Some installations support cover images:
1. Edit profile
2. Upload cover image
3. Position and save

## Privacy Settings

### Profile Visibility

Control who can see your profile:
- **Public**: Everyone can view
- **Private**: Only you can view
- **Restricted**: Only approved users

### Contact Options

Enable or disable:
- **Allow Contact**: Let others contact you
- **Email Notifications**: Receive notifications

## Mentions in Comments

You can mention other users in comments:

1. Type `@` in a comment
2. Start typing a username
3. Select from suggestions
4. The mentioned user receives a notification

## Comments with Timestamps

Comments can include timestamps that link to specific video moments:

### Format

Use `HH:MM:SS` or `MM:SS` format:

```
Great moment at 1:23:45!
```

or

```
Check this out at 5:30
```

### Display in Timebar

Comments with timestamps appear as dots on the video timeline:

- **Hover**: Preview the comment
- **Click**: Jump to that moment
- **Playback**: Comment appears when reached

## Search and Discovery

### Finding Users

- Use the search function
- Browse user listings
- Click on usernames in comments

### Finding Content

- Search by username
- Browse user profiles
- View user media galleries

## Best Practices

1. **Complete your profile**: Add bio and picture
2. **Use channels**: Organize content thematically
3. **Engage**: Comment and interact with others
4. **Privacy**: Set appropriate privacy levels
5. **Keep updated**: Regularly update your profile
