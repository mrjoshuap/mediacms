# Getting Started - Users

Welcome to MediaCMS! This guide will help you get started using MediaCMS to upload, manage, and share your media content.

## What is MediaCMS?

MediaCMS is a modern, open-source video and media content management system. It allows you to:

- Upload videos, audio, images, and PDFs
- Organize your media with categories and tags
- Share media publicly or keep it private
- Create playlists
- Add subtitles and captions
- Embed media on other websites

## Creating an Account

1. Navigate to your MediaCMS instance
2. Click the **Sign In** button (if available)
3. Click **Register** to create a new account
4. Fill in your details:
   - Username
   - Email address
   - Password
5. Click **Register**

> **Note**: Some MediaCMS installations may require email verification or admin approval before you can log in.

## Your First Upload (5 Minutes)

### Step 1: Click Upload Media

Click the **Upload Media** button in the top-right corner of the screen.

### Step 2: Select Your File

- Click **Browse** to select a file from your computer, or
- Drag and drop a file onto the upload area

### Step 3: Wait for Upload

The file will upload automatically. You can pause and resume the upload if needed.

### Step 4: Add Metadata

Once uploaded, click **View Media** and then **Edit Media** to add:
- Title
- Description
- Category
- Tags

### Step 5: Publish

Choose your media visibility:
- **Public**: Visible to everyone
- **Unlisted**: Accessible via direct link only
- **Private**: Only you can see it

Click **Save** to publish your media!

## Basic Navigation

- **Home**: Browse all public media
- **My Media**: View your uploaded content
- **Upload**: Upload new media
- **Playlists**: Create and manage playlists
- **Profile**: Edit your profile and settings
