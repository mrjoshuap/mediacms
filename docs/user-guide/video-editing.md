# Video Editing

Trim videos, create segments, and edit your content directly in MediaCMS.

## Video Trimmer

MediaCMS includes a built-in video trimmer that allows you to:
- Trim videos to specific segments
- Replace the original video
- Create new videos from segments
- Split videos into multiple segments

## Accessing the Video Trimmer

1. Navigate to your video page
2. Click **Edit Media**
3. Find the **Trim Video** option
4. Click to open the trimmer

## Trimming a Video

### Basic Trim

1. Open the video trimmer
2. Use the timeline to select start and end points
3. Preview the trimmed segment
4. Choose an action:
   - **Replace Original**: Replace the current video
   - **Save as New**: Create a new video file
   - **Create Segments**: Split into multiple videos

### Creating Segments

To split a video into multiple segments:

1. Open the trimmer
2. Select your first segment
3. Click **Add Segment**
4. Select the next segment
5. Repeat for all segments
6. Click **Create Segments**

Each segment becomes a separate video file.

## Processing Time

### Instant Processing

If your video has finished processing (all resolutions encoded):
- Trimming happens instantly
- You see results immediately
- No waiting required

### Processing Required

If your video is still processing:
- Trimming triggers full processing
- Takes time depending on video length
- You'll see a "Processing" message
- Original video remains available during processing

## Video Preview

The trimmer shows:
- **Timeline**: Visual representation of your video
- **Preview**: See what you're trimming
- **Time markers**: Start and end times
- **Duration**: Length of selected segment

## Best Practices

1. **Plan your cuts**: Know what you want before trimming
2. **Use preview**: Always preview before saving
3. **Keep originals**: Consider saving as new instead of replacing
4. **Test segments**: Verify segments work before deleting originals

## Limitations

- Trimming requires video processing to complete first (for instant results)
- Large videos may take time to process
- Some formats may have limitations
- Original quality is preserved

## Troubleshooting

### Trimmer Not Available

- Verify video has finished processing
- Check if feature is enabled
- Ensure you have edit permissions

### Processing Takes Too Long

- Large videos take time
- Check transcoding queue status
- Contact administrator if stuck

### Trim Not Working

- Verify video format is supported
- Check processing status
- Try refreshing the page
