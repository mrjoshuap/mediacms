# Playlists

Create and manage playlists to organize your media content.

## Creating a Playlist

1. Navigate to **Playlists** in the main menu
2. Click **Create Playlist**
3. Enter a name and description
4. Click **Create**

## Adding Media to Playlists

### From Media Page

1. Open a media item
2. Click **Add to Playlist**
3. Select an existing playlist or create a new one
4. Click **Add**

### From Playlist Page

1. Open your playlist
2. Click **Add Media**
3. Search and select media
4. Click **Add**

## Managing Playlists

### Reorder Media

1. Open your playlist
2. Drag and drop items to reorder
3. Changes save automatically

### Remove Media

1. Open your playlist
2. Click the remove button on an item
3. Confirm removal

### Edit Playlist

1. Open your playlist
2. Click **Edit**
3. Change name, description, or visibility
4. Save changes

### Delete Playlist

1. Open your playlist
2. Click **Delete**
3. Confirm deletion

**Warning**: Deleting a playlist does not delete the media items.

## Playlist Visibility

Playlists can be:
- **Public**: Visible to everyone
- **Unlisted**: Accessible via direct link
- **Private**: Only you can see it

## Playlist Limits

- Maximum media per playlist: Configurable (default: 100)
- Maximum playlists per user: No limit (configurable)

## Playback

### Play All

Click **Play** to start playing all items in the playlist sequentially.

### Shuffle

Some players support shuffle mode for random playback.

## Tips

1. **Organize by theme**: Create playlists around topics
2. **Use descriptions**: Help others understand your playlist
3. **Reorder thoughtfully**: Put important content first
4. **Keep updated**: Add new content regularly
