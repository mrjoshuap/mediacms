# Managing Media

Learn how to edit, organize, and manage your media files in MediaCMS.

## Editing Media

### Access Edit Mode

1. Navigate to your media page
2. Click **Edit Media** button
3. Make your changes
4. Click **Save**

### Editable Fields

- **Title**: Media title
- **Description**: Detailed description
- **Category**: Organize by category
- **Tags**: Add tags for searchability
- **Visibility**: Public, Unlisted, or Private
- **Allow Downloads**: Enable/disable downloads
- **Poster Image**: Custom thumbnail

## Organizing Media

### Categories

Categories help organize your content:

1. Select a category when editing media
2. Browse media by category
3. Categories are managed by administrators

### Tags

Tags improve searchability:

1. Add multiple tags separated by commas
2. Tags are searchable
3. Click tags to find related content

## Media Visibility

### Public

- Visible to everyone
- Appears in search results
- Listed on category pages

### Unlisted

- Accessible via direct link only
- Not shown in search or listings
- Share the link to allow access

### Private

- Only you can see it
- Not accessible to others
- Can grant specific user permissions

## Download Settings

### Enable Downloads

1. Edit your media
2. Check **"Allow Downloads"**
3. Save changes

### Download Options

When downloads are enabled, viewers can download:
- Transcoded versions (various resolutions)
- Original file (if allowed)

## Media Permissions

### Granting Access

For private media, you can grant access to specific users:

1. Edit media
2. Add users with permissions:
   - **Viewer**: Can view the media
   - **Editor**: Can view and edit
   - **Owner**: Full control

## Deleting Media

1. Navigate to your media
2. Click **Delete** (if available)
3. Confirm deletion

**Warning**: Deletion is permanent and cannot be undone.

## Bulk Actions

Some installations support bulk actions:

- Select multiple media items
- Apply actions to all selected items
- Available actions depend on your permissions
